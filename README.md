### 🧠 O que cada projeto treina

* **Fórmulas:** `SE`, `SEERRO`, `PROCV`/`PROCX`, `ÍNDICE` + `CORRESP`, `SOMASES`, `CONT.SES`, `MÉDIASE`, `SOMARPRODUTO`, `DATADIF`.
* **Análise e Visualização:** Tabelas dinâmicas, segmentação de dados, gráficos combinados, formatação condicional, conjuntos de ícones.
* **Organização de Dados:** Tabelas estruturadas, validação de dados, listas suspensas, proteção de células.
* **Automação e Preparação de Dados:** Power Query (Obter e Transformar Dados).

## 📂 Estrutura do Repositório

Cada projeto possui sua própria pasta organizada da seguinte forma:

```text
XX-nome-do-projeto/
├── projeto.xlsx        # Planilha principal
├── README.md           # Objetivo, recursos usados, como usar e aprendizados
├── prints/             # Imagens da planilha em funcionamento
└── projeto.pdf         # Exportação para visualizar sem baixar o Excel

O GitHub não exibe o conteúdo de arquivos .xlsx no navegador. Por isso, cada pasta inclui prints e um PDF para quem quiser ver o resultado rapidamente.

---

🚀 Como Usar

1. Escolha o projeto: Clique na pasta do projeto que deseja explorar.
2. Leia a documentação: Acesse o `README.md` dentro da pasta para entender o problema de negócio e as técnicas aplicadas.
3. Visualize os resultados: Confira os resultados de forma rápida observando as imagens na pasta `prints/` ou abrindo o arquivo `.pdf`.
4. Inspecione a planilha: Caso queira analisar as fórmulas, dados e estruturas, baixe o arquivo `.xlsx` e abra-o no Microsoft Excel.
