Excel Data Analysis

Projetos em Excel com foco em análise de dados: tabelas dinâmicas, dashboards, indicadores (KPIs), Power Query e automação de relatórios. Cada projeto resolve um problema prático e vem com planilha, prints e explicação.

Todos os dados deste repositório são fictícios, criados apenas para fins de estudo e demonstração.

# Estrutura do repositório

Cada projeto fica em uma pasta própria:

XX-nome-do-projeto/

├── projeto.xlsx        # planilha principal

├── README.md           # objetivo, recursos usados, como usar e aprendizados

├── prints/             # imagens da planilha em funcionamento

└── projeto.pdf         # exportação para visualizar sem baixar o Excel

O GitHub não exibe o conteúdo de arquivos .xlsx no navegador. Por isso, cada pasta inclui prints e um PDF para quem quiser ver o resultado rapidamente.

- Como usar

Clique na pasta do projeto que quer ver.
Leia o README.md da pasta para entender o problema e as técnicas usadas.
Veja os prints ou o PDF.
Se quiser explorar as fórmulas, baixe o arquivo .xlsx e abra no Excel.

- Ferramentas

Microsoft Excel (versão 2016 ou superior) e Power Query. Versionamento com Git e GitHub.
